# Sample images

The three PNGs here are synthetic placeholders (flat-color shapes), generated only to verify
the upload/inference/storage pipeline end to end. A shape on a plain background won't match
any real ImageNet class meaningfully, so the label ResNet-50 returns for them is not the
point, only that the request succeeds and a row shows up in the grid.

For the actual webinar, replace these with real photos (animals, everyday objects, vehicles),
ImageNet-1000 classes cover a wide range of them and the demo is far more convincing with
recognizable results.
